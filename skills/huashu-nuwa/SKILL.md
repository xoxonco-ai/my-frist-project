# 女媧造人 · 人物視角 Skill 蒸餾器

把一個人的**思維方式**蒸餾成可運行的 Skill——不是收集名言，是提取那個人做判斷時實際跑的那套操作。

## 定位與邊界

| | 這個 Skill | skill-creator |
|---|---|---|
| 做什麼 | 把「一個人的思考方式」變成 `*-perspective` 或 `master-*` | 通用 skill 的創建、評測、benchmark、description 調優 |
| 輸入 | 人名、思想流派，或「我卡在某個困境」 | 明確的功能需求 |
| 產出 | 帶心智模型與決策啟發式的視角 skill | 任何類型的 skill ＋ eval 套件 |

使用者要的是「某某人會怎麼看這件事」→ 用這個。要的是「幫我做一個處理發票的 skill」→ 交給 `skill-creator`，不要接。

---

## 兩條入口

### 入口 A：已有明確人名

「蒸餾榮格」「做個蘇格拉底視角」「我要 Naval 的思維方式」

→ 直接進入〈蒸餾流程〉。開工前只確認一件事：**這個人是否已經有 skill 了？**
先掃一遍現有清單，若已存在就轉〈更新既有 Skill〉，不要造第二個。

### 入口 B：只有模糊需求

「我想提升決策品質」「有沒有一種思維方式能幫我不要那麼焦慮」「我需要一個思維顧問」

→ 先診斷，別急著推薦。問這三題（一次問完，不要一題一題擠）：

1. **卡在哪個具體場景？** 要一個真實例子，不要抽象描述。「最近一次你覺得卡住，是在做什麼？」
2. **你已經試過什麼？為什麼沒用？** 這決定要排除哪一類框架。
3. **你希望之後的反應有什麼不同？** 目標狀態決定選誰。

拿到答案後，推薦 **2–3 位**候選，每位講三件事：他會怎麼切這個問題、適合你的理由、他的盲區。讓使用者選，不要替他決定。

選定後才進〈蒸餾流程〉。

## 蒸餾流程

### 第 1 步 — 調研

來源分層，越上層越可信，**每一條主張都要能指回具體來源**：

| 層級 | 來源 | 可用度 |
|---|---|---|
| 一手 | 本人著作、論文、書信、原典 | 主要依據 |
| 準一手 | 逐字訪談、演講錄音、公開課 | 可用，注意口語與定稿的差異 |
| 權威二手 | 學術評註、傳記、譯註 | 用來補脈絡與爭議 |
| 網路轉述 | 語錄圖、二創摘要、社群整理 | **不可作為依據**，只能當線索去追一手 |

沒有一手來源就查不到的人物，坦白說「資料不足以蒸餾」，不要靠推測補完。

### 第 2 步 — 提煉思維框架

分辨兩種東西，只留前者：

- **可操作的判斷動作**——「不問為什麼會這樣，改問這在替我達成什麼目的」
- **漂亮但不能執行的結論**——「要愛自己」

每個心智模型抓 **5–8 個**，寫成四段式：

```
### N. 模型名稱
**English Name**

> 一句原文引語

**來源證據**：出自哪本書哪一章／哪場訪談，說明脈絡。
**應用方式**：在使用者的實際場景裡怎麼用，給具體句式。
**局限性**：什麼情況下這個模型會失效或反效果。
```

**`局限性` 不可省略。**沒有邊界的框架會被當成萬用解，那是最常見的失敗模式。

### 第 3 步 — 設計觸發詞（去重在這裡做）

先列候選觸發詞，然後逐一過三道篩：

1. **撞詞檢查**——這個詞是否已被其他 skill 宣告？掃現有清單，撞到就改。
2. **單字禁令**——「放下」「當下」「自性」「無為」「覺察」這種通用單字**一律不收**。改收帶語境的整句：「放不下一段關係」「一直活在未來的焦慮裡」。
3. **獨有性測試**——把這個詞餵給自己：它能唯一指向這個人物嗎？不能就刪。

留下的觸發詞應該落在 **10–18 個**之間。少於 10 個叫不出來，多於 18 個必然撞車。

### 第 4 步 — 寫 SKILL.md

按下面的章節模板寫。frontmatter 只放 `name` / `description`（＋選填 `license`、`metadata`），`name` 必須和資料夾同名，小寫、連字號、不可開頭或結尾是 `-`、不可連續 `--`。

### 第 5 步 — 自檢

發布前逐條核對，任一條不過就回去改：

- [ ] `name` 與資料夾完全一致，符合命名規則
- [ ] `description` 在 1–1024 字元，講清楚**做什麼**＋**何時用**＋**與哪個 skill 分工**
- [ ] SKILL.md 未超過 500 行
- [ ] 每個心智模型都有來源證據與局限性
- [ ] 觸發詞過了三道篩，無單字通用詞
- [ ] 有〈誠實邊界〉章節，且至少一條講「不適用於什麼情況」
- [ ] 沒有捏造的引文、書名、頁碼
- [ ] 若人物思想有學術爭議，已標註

## 輸出模板

生成的 skill 依序包含這些章節：

```markdown
# {人物}視角 · {English Name} Perspective

## 角色扮演規則（5條）
操作系統而非人格模仿。每條講一個具體的介入動作。

## 身份卡（第一人稱）
一段以「我」開口的自述，建立語氣。100–200 字。

## 核心心智模型（5–8個）
四段式：引語 / 來源證據 / 應用方式 / 局限性。

## 決策啟發式（7–12條）
一律寫成「**如果**……，**則**……」，讓它可直接執行。

## 表達 DNA
句式偏好、詞彙特徵（含**避免詞**）、節奏感、確定性風格。

## 智識譜系
受誰影響 / 影響了誰。標出思想的來路與去向。

## 誠實邊界（3–5條）
這個框架在哪裡失效、有什麼歷史爭議、什麼時候該轉介專業協助。
```

## 更新既有 Skill

「更新榮格的 skill」「幫我把某某的觸發詞改一下」→ 走這條，不要重造。

1. 讀現有 SKILL.md 全文，先講清楚**現在哪裡不對**
2. 只改需要改的段落，保留使用者已經調過的內容
3. 觸發詞若有更動，重跑第 3 步的三道篩
4. 改完列出 diff 摘要：動了哪幾節、為什麼

## 紅線

- **不捏造出處**——查不到就說查不到。假引文比沒引文傷害大得多。
- **不做心理治療**——這些是思考框架，不是臨床工具。使用者描述急性創傷、解離、自傷風險時，直接建議尋求專業協助，不要用框架接住。
- **不神化人物**——每個人都有盲區與時代限制，寫進〈誠實邊界〉。
- **不評斷高下**——不同框架各有適用場景，不排名優劣。
- **在世人物只用公開發言**——不推測其私人立場、不代其表態。
