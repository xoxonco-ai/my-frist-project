## 🎨 視覺識別（近黑底・燙金・黑體・中央暗角）

```
GOLD    = #E4C77E   /* 主燙金：內文、編號、金線 */
GOLD_HI = #F5E4AC   /* 更亮金：強調關鍵詞 <span class="em"> */
FONT    = 'WenQuanYi Zen Hei','PingFang TC', sans-serif   /* 系統黑體，非明體 */
```

- **字體**：**黑體（sans）**，不是明體。網路字型（Google Fonts / jsdelivr）在沙箱會被 proxy 擋 403，只能用系統安裝的 CJK 黑體。
- **暗角**：**中央** radial-gradient 由中心往外淡出的深色遮罩，讓字在任何底圖上都夠清楚（不是左側/單邊暗角）。
  - 輪播：`radial-gradient(62% 46% at 50% 51%, rgba(6,4,2,.62) 0%, .4@48%, 0@100%)`
  - 限動：`radial-gradient(60% 42% at 50% 46%, rgba(6,4,2,.66) 0%, .42@50%, .08@100%)`
- **字全部置中**，`line-height` 輪播 1.85 / 限動 1.75；`--force-device-scale-factor=1`。
- **底圖**：`bg/bg1.png ~ bg9.png` 官方 9 張黑金背景（放射線／木紋／星圖質感），品牌 tagline「看見戲・解開碼・回到家」已烘在底圖裡，**腳本不另加 wordmark**。

## 🌿 敘事 DNA

- 招牌句型「妳不是 X，妳只是 Y」；痛點對號 → 翻轉 → 一個小練習。
- **anti-hype 硬邊界**：不恐嚇／不神化／不絕對預測／不成功學／不顯化神話／不醫療療效宣稱。
