# 出發文卡 · 使用指南（USAGE・官方黑金 v5）

在**這個 repo 開一個 Claude Code session**，直接說要哪天，Claude 會讀當天發文包 → 套官方黑金 → 出圖 → 交付。

---

## 每次出圖：跟 Claude 說

> 出 D05 的發文卡（輪播＋限動）

或更明確：

> 用 render_carousel.py 出 D05（房間：回家）7 張輪播；再用 render_story.py 出 D05 的 2 張限動。

**Claude 會做的事**
1. 讀當天發文包：`2_1230_IG輪播貼文`（輪播 7 張分鏡）＋ `4_1700_IG限動互動`（限動 2 張）
2. 依房間查 ROOM_BG 選底圖（見幻筆記→bg1、浮生解碼→bg3、經在人間→bg2、登出指南→bg9、回家→bg7、木雕哲學→bg6、複盤互動→bg5）
3. 把文字填進 `render_carousel.py` / `render_story.py` 的 DAYS，跑出圖
4. Pillow 轉 JPEG(88)、一天一包 zip、傳給你 → 你拖進 Drive 對應 D0X 資料夾

## 版型速記

| 類型 | 尺寸 | 張數 | 結構 |
|------|------|------|------|
| 輪播 | 1080×1350（4:5） | 7 | 語錄封面 + 5 內文 + 練習卡（含 CTA 關鍵字）|
| 限動 | 1080×1920（9:16） | 2 | 投票 + 問答（順序照發文包；導流關鍵字放 caption）|

限動互動貼圖（投票/問答貼紙）Meta API 不能自動發——在 IG App 手動貼到對應那張上。

## 注意事項

- 這個雲端環境是**臨時的**：程式碼在 git 裡（不會掉），但**底圖 `bg/` 不進 git**（大檔）。
  換環境時 `bg/` 會是空的 → 要重新放官方 9 張黑金底圖（拖進對話，或從官方來源複製）。
- 字型是系統**黑體**（官方規格就是黑體，不是明體）。
